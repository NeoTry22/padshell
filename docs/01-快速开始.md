# 01 快速开始

## 1. 硬件与烧录

1. ESP32-S3-DevKitC-1 **N16R8**（其他 S3 板也可，注意 Flash/PSRAM 配置）。
2. 安装 [PlatformIO](https://platformio.org/)（VSCode 插件或 CLI）。
3. 改 `firmware/src/main.cpp` 顶部常量：
   - `WIFI_SSID` / `WIFI_PASS`：你的 2.4G WiFi（**必须 2.4G**，BLE 与 5G 频段共存差）
   - `AUTH_TOKEN`：强随机串（所有 HTTP 路由的门禁）
4. 烧录：`pio run -e esp32s3 -t upload`；串口监视 `pio device monitor`（115200），
   `[READY] 控制台: http://x.x.x.x/?token=...` 即成功。
5. 已联网后也可运行时改 WiFi：`/config?ssid=新名字&pass=新密码`（重启生效）。

## 2. iPad 端（PadShell）

见 [ipadclient/README.md](../ipadclient/README.md)：GitHub Actions 免费编译未签名 IPA →
Sideloadly 个人签名（免费 Apple ID：3 台设备/10 个 App/证书 7 天过期）→
设置 → 通用 → VPN与设备管理 → 信任证书 → 打开 App → 点广播按钮 → 选 PadShell Broadcast。

## 3. 配对

iPad 设置 → 蓝牙 → 点 **ESP32-PadMouse** → 配对。之后 ESP32 断电重启会自动回连，
无需重新配对。

## 4. 控制台

浏览器开 `http://<esp32-ip>/?token=<你的token>`：

- **点画面即点击**（分数坐标自动换算）；右上角有 10% 标定网格辅助。
- 状态栏：图床大小 / 上传时间 / BLE 状态 / 标定参数 / IP6。
- 遥测字段含义见 [04-故障排查.md](04-故障排查.md)。

## 5. 首次校准（必做）

iPadOS 指针加速是非线性的，每台 iPad 的「指针速度」设置也不同——
**不校准就无法精准落点**。流程约 10 分钟：保持 PadShell 广播开启 +
iPad 打开标定页 `http://<esp32-ip>/calib?token=...`，按
[02-校准与坐标系统.md](02-校准与坐标系统.md) 操作。
