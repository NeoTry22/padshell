# 05 故障排查

## 一图流判读

```
点击不动？ ── iOS 侧：辅助触控开？鼠标键必须关？ ── 否 → 修设置
   │是
   ├─ /status 的 rms=? ── 断开 → 重启 ESP32 / iPad 蓝牙开关重开
   ├─ 偏移？ ── op=syncbase 重建基准（校准改过 cx/cy 必做）
   └─ 全偏？ ── 重校（见 02），或「指针速度」滑块动过没
画面不动？
   ├─ PadShell 广播还开着？（重启 iPad 后必断，要人手点）
   ├─ /status 的 upok 涨吗？upfail>0 ？ ── >0 → 帧体积过大，见 03
   ├─ fid ≈ upok ？ ── 不等 → 上传链路问题
   └─ 控制台 fid 不涨？ ── 拉帧链路：token / 网络
登录不上？
   ├─ token 对吗（区分大小写）？
   ├─ 403 连续 5 次 → 同 IP 拉黑 10 分钟（等 or 重启 ESP32）
   └─ /status 的 banhits 在涨？ ── 有人/脚本在乱撞你的 token
```

## 常见坑速查

| 症状 | 原因与解法 |
|---|---|
| 指针完全不响应 | iPad 设置：辅助触控要**开**，「鼠标键」要**关**；蓝牙列表里设备应为「已连接」 |
| 改了 Report Map 类参数后失灵 | 蓝牙列表 ⓘ → **忽略此设备** → 重新配对（系统缓存了旧描述符） |
| 点击整体偏移 | `syncbase`；或指针速度滑块动过 → 重校 |
| 广播总掉 | 免费签名过期（App 都打不开）；或连续 300 次上传失败后扩展自动停 |
| 上传狂失败 | 帧体积超容量（03 的容量模型）；降 edge/q |
| 控制台空白/403 | token 错或被拉黑；确认 URL 带 `?token=` |
| 扩展连不上 ESP32 | 扩展编译期常量填的地址不对 → 改 `SampleHandler.swift` 顶部常量重编译 |
| ESP32 重启后全偏 | BLE 回连后系统指针位置变了 → `syncbase` |

## 遥测字段（/status）

| 字段 | 含义 |
|---|---|
| `upok` / `upfail` | 图床收到/失败的上传总数；健康=upok 涨且 upfail=0 |
| `fid` | 最新帧号（单调递增），`/shotf?since=N` 增量拉取用 |
| `a403` | 鉴权失败次数；异常涨=有人在乱撞 |
| `banhits` | 被拉黑 IP 的被拒请求数 |
| `rms` | BLE 连接状态（断开≠配对丢失，重启 ESP32 会自动回连） |
| `rx/ry` | 指针当前视口分数（校准回传用） |
| `qse/qql` | 当前生效的帧长边/质量（广播扩展每 20s 拉取跟随） |

## 玄学重置三板斧（顺序执行）

1. iPad 蓝牙开关关-开（10 秒）。
2. ESP32 断电重启（NVS 参数都在，不怕）。
3. 都不行 → 蓝牙列表 ⓘ 忽略设备重新配对 + iPad 重启。
