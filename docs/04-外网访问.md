# 04 外网访问（Tailscale 子网路由）

方案目标：人在外地，用手机/电脑浏览器像局域网一样控制家里的 iPad。
原则：**ESP32 和 iPad 跑不了隧道客户端**（都不能装 Tailscale），所以需要一台
局域网内常开的主机（NAS / 树莓派 / 闲置电脑）做子网路由。

## 架构

```
外地设备 ──WireGuard 加密隧道──▶ Tailscale 协调服务 ◀──隧道── 家里常开主机(NAS/树莓派)
                                                            │ 子网路由 192.168.x.0/24
                                                     家里 ESP32 / iPad / 其他设备
```

- 外地设备直接访问家里内网 IP（如 `http://192.168.1.100/?token=...`），如同在家。
- 隧道端到端 WireGuard 加密；**路由器不做任何端口映射**，公网暴露面为零。
- 视频流（iPad→ESP32）始终在内网；隧道只承载控制台 HTTP，不增加视频带宽负担。

## 步骤概要

1. 注册 [Tailscale](https://tailscale.com/)（免费档 3 用户/100 设备，够用）。
2. 常开主机装 Tailscale 并 `--advertise-routes=<你家网段>/24`（例：`192.168.1.0/24`）。
   - 群晖/威联通/绿联等 NAS：优先找官方套件；ARM 小板用官方一键脚本；
   - x86 Linux 无 Docker 也无包时可用官方静态二进制 + systemd 常驻（本项目实测路线）。
3. Tailscale 管理台 → Machines → 该主机 → **Approve** 子网路由；**Disable key expiry**
   （否则 180 天后掉线）。
4. 外地设备装 Tailscale 登录同一账号，开关打开即可。

## 安全要点

- 协调服务器只负责握手撮合，流量不经过它（WireGuard 点对点加密）。
- 仍然**保留 ESP32 的 token 门禁**：隧道内是"半个内网"，别裸奔。
- 管理台里只批准你需要的网段，不要 `0.0.0.0/0` 全量出口（除非你明确要）。

## 备选方案对比（为什么选 Tailscale）

| 方案 | 结论 |
|---|---|
| 路由器端口映射 + DDNS | ESP32 控制台裸奔公网，明文 HTTP+弱口令，不推荐 |
| frp 自建 | 需要有公网 VPS，多一个暴露面要自己维护 |
| IPv6 直连 | 可行但外地网络 IPv6 覆盖不稳，且仍需防火墙收敛 |
| **Tailscale 子网路由** | ✅ 零端口暴露、加密、免费档够用 |
